# Android Learning

A small Android app for learning Jetpack Compose. The UI is Kotlin, Material 3, and a handful of screens you can tap through on a phone or emulator.

Open this folder in Android Studio and run the `app` configuration.

## Lessons

- **Composables** — UI as a function of the data you pass in
- **State** — a value the UI reads, and how changing it redraws the screen
- **Layout** — the same content arranged in a column, a row, or a box
- **Material 3** — buttons, cards, and a theme switch

## Toolchain

- Android Gradle Plugin 9.5.1, with its built-in Kotlin (2.2.10)
- Jetpack Compose BOM 2026.09.00
- compileSdk 37, minSdk 26, targetSdk 36
- JDK 17 or newer. Android Studio’s bundled JDK is enough.

Android Studio downloads the Android SDK the first time you sync the project.
